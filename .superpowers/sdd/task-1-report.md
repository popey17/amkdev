## Review fix: clean-state type checking

Updated the `typecheck` script in `package.json` from:

```text
tsc --noEmit
```

to:

```text
next typegen && tsc --noEmit
```

This makes type checking generate the route declarations imported by `next-env.d.ts` rather than relying on types left behind by a previous development server or production build.
